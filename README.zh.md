# dsh-ledger · 聊天记账

在 DSH 里用一句话记账：家里花销、店里的现金和赊账，都记在同一本账上，但**分成三本帐看**，永远不混：

| 看什么 | 从哪来 | 用途 |
| --- | --- | --- |
| 现金真的动了多少 | 卖出实际收到的钱、进货实际付出的钱、还款、转账 | 抽屉里的钱对不对得上 |
| 外面还欠多少（应收/应付） | 赊账 − 已收 − 已还，按人 FIFO 核销 | 谁该还钱、该给谁钱 |
| 赚了多少 | v1 **不算** | 没记成本价，硬算会骗人 |

设计文档：[DESIGN.md](./DESIGN.md) · 悬浮看板设计：[DASHBOARD.md](./DASHBOARD.md) · 周末计划：[WEEKEND.md](./WEEKEND.md)

## 现在能做什么

- **家里**：支出、收入、退款、转账、调整；自动归类（餐饮/交通/居住/购物/医疗/娱乐/学习/通讯/人情/旅行/宠物/其他）。
- **店里**：卖出（零售/批发）、进货、收到还款、付货款、退货、盘点、从店里取走。
- **补记过去**："上周三买了两条烟" 会记到上周三，汇总自动跟着变。
- **赊账**：老陈拿 20 双先欠着 → 应收 + 账龄；还了一部分 → FIFO 冲最早的账。
- **谁记的**：从 dsh-im 的 `<dsh_im_source>` 里取 `senderName`（妈/爸/杨），记进每条记录；同名同金额 10 分钟内重复会提醒。
- **日报/月报**：聊天里出，也能导出 Obsidian markdown 和 CSV。
- **改错**：说"最后那笔改成 680" 就行，不用报 id；改账本、作废、恢复都支持。
- **夜间小结**：默认 21:30 一条（店里每日、家里每周一），写到 `<dataDir>/nightly/`。
- **设置面板**：设置 → Ledger，最近一个月看板（支出类目、应收应付、近六月趋势、最近记录）+ 12 项配置。见[设置面板](#设置面板ledger)。
- **右下角看板**：任意日期范围的账目看板（图表 + 摘要 + 分人），默认近 30 天。见[右下角看板](#右下角看板ledger-按钮)。

## 还不能做（故意留到下一步）

- 库存与毛利：不记货号就不做库存；"这个月赚多少" 只答"卖出减付出"。
- 预算：本项目不做预算。
- 网页面板上的**写操作**：面板这一版只看不改账，改数仍然走聊天（改错要留回执）。
- 多币种：只记人民币。

## 怎么用（例句）

家里：

| 你说 | 记成 |
| --- | --- |
| 午饭 32 | 支出 32，餐饮 |
| 打车 18，晚饭 60 | 两笔，交通 + 餐饮 |
| 昨天买菜 85 | 支出 85 记到昨天 |
| 发工资了 12000 | 收入 12000 |
| 上周三充话费 100 | 支出 100 记到上周三 |

店里：

| 你说 | 记成 |
| --- | --- |
| 卖了 480，微信收的 | 卖出 480，已收 480 |
| 老陈拿了两双，先欠着 480 | 卖出 480，老陈欠 480，应收 +480 |
| 老陈还了 300 | 收到还款 300，老陈还欠 180 |
| 进了一批货 6000，先欠着 | 进货 6000，应付 +6000 |
| 付厂家 4000 | 付货款 4000，应付 −4000 |
| 从店里拿一双自己穿 | 取走一双（不算店里开支） |
| 这个月卖了多少 / 外面还欠多少 | 经营月报 / 欠款表 |

## 安装

插件已链接进 `desktop` profile，**重启 DSH 生效**：

~~~bash
# 已经执行过的两步（供参考/重装）
cd ~/.dsh/profiles/desktop
pnpm add "dsh-ledger@link:/Volumes/Zuyang/deepseek_harness_plugin/dsh-ledger"
# 并确认 package.json 的 dsh.profile.bundles 里有 "dsh-ledger"
~~~

重启后打开设置 → 插件，应能看到 `dsh-ledger`；聊天里说"午饭32"会看到回执。

## 配置

部署级配置写在 profile 的 patch 里（`~/.dsh/profiles/desktop/cordis.patch.yml`）。插件已自带一条，取消注释即可改：

~~~yaml
- id: dsh-ledger
  name: dsh-ledger
  config:
    # 账本放哪：默认 ~/.dsh/ledger。支持 ~、$HOME、绝对路径；相对路径按家目录算。
    # 换目录 = 换一本新账，旧数据不会自己搬过去（见下一节"搬家"）。
    # dataDir: ~/Documents/Ledger
    defaultActor: yang            # 认不出来是谁记的时算谁的
    defaultBook: home             # 没说是店里还是家里时的默认账本
    shopName: 店里
    nightlyTime: "21:30"
    purchaseSettlementDefault: cash   # 进货没提"欠着"时按付清记
    autoCommit: true
    commitDebounceSec: 60
~~~

所有键在 `Config` 里都带中文说明，`--dump-config-schema` 能直接看到。运行时状态（谁上次记的哪本、夜间已发记录、类目别名）在 `<dataDir>/meta.json`，不用手改。

### 换个存储位置（搬家）

1. 先停 DSH（账本不需要停，但换了位置要重启才生效）；
2. 把旧账本整目录拷过去：`cp -a ~/.dsh/ledger/. ~/Documents/Ledger/`；
3. 在 patch 里写 `dataDir: ~/Documents/Ledger`，重启；
4. 聊天里 `ledger_doctor` 应显示"（自定义位置）"和你原来的记录条数。

忘了拷也没关系：启动日志会 warn，`ledger_doctor` 会报"默认目录里还有 N 条旧记录"，把命令复制粘贴即可。

## 设置面板（Ledger）

重启 DSH 后，**设置 → Ledger**（排在 Diary 和 Memory 之间）就是账本的看板 + 配置页：

| 区域 | 内容 |
|---|---|
| 顶部 | 月份切换（最近六个月，默认当月）、记录条数、刷新 |
| 指标 | 家里支出 / 家里收入 / 店里卖出 / 现金净流 / 应收未收 / 应付未付 |
| 家里花在哪 | 类目横向占比条（金额 + 百分比） |
| 欠账 | 应收、应付两张小表（谁、欠多少、多久了） |
| 近六个月 | 家里支出与店里卖出的趋势条 |
| 最近记录 | 最近 12 条，含"谁记的" |
| 配置 | 12 个可改项，保存后**需重启 DSH** 才生效 |
| 底部 | 账本目录（默认/自定义）、git 状态、隔离行数、配置文件路径 |

面板里的值存在 `~/.dsh/ledger-ui.json`，**优先级高于 profile 里的 patch**（面板不能安全改写部署方拥有的 YAML）。每项右边有来源徽标：`面板` / `配置文件` / `默认`；想回到 patch 或默认值，把它清空再保存即可。

数据通路是插件自己的 HTTP 路由（`/api/ledger/summary`、`/api/ledger/config`）——DSH 的 settings wire 只服务宿主白名单，第三方插件永远写不进去。

排障：

- 设置里没有 Ledger：确认 `~/.dsh/profiles/desktop/package.json` 的 `dsh.profile.bundles` 里有 `dsh-ledger`，然后重启。
- 面板一直"正在读账本…"：说明这两条路由没起来（headless/无 web 服务时本来就没有），桌面端重启一次即可。

## 右下角看板（Ledger 按钮）

聊天界面右下角有一个圆形「账」按钮，点开是账本看板弹窗（Esc 或点遮罩关闭）：

- **范围**：近 7 天 / 近 30 天 / 本月 / 上月；也能直接选起止日期（默认近 30 天，超过 62 天自动按周聚合）。
- **视角**：`整体`（家里花在哪、店里卖出与现金）或 `分人`（谁记的账：排行、每日堆叠、未归类笔数）。
- **账本**：两本 / 家里 / 店里。
- **头部数字**：家里支出（已扣退款）、家里收入、店里卖出、现金净流、应收未收。
- **图表与明细**：每日支出柱（有收入时叠一条细线）、类目占比条、最近记录、应收应付（截至范围结束日）。
- **摘要**：一两句人话总结。句式和聊天里完全一致——面板和聊天调用同一个聚合函数，不会各说一套。
- **分人改名字**：点名字直接改，只写 `meta.actorNames` 别名，历史记录一个字不动；清空就退回显示微信 id。

弹窗打开时每 30 秒重读一次文件，聊天里刚记的一笔，打开面板就能看到。「分人」看的是**谁记的账**，不是谁花的钱。

面板只读：改数、作废、补记仍然走聊天（留回执）。

## 谁记的（entered_by）

dsh-im 会把发送者写进消息文本（`<dsh_im_source>` 块），插件按这个顺序认人：

1. 模型显式传的 `entered_by`；
2. 块里的 `senderName`（微信昵称/备注名）；
3. **没有昵称就用 `senderId`**（微信分配给这个人的唯一 id，难看但不会认错人）；
4. 都没有就用配置里的 `defaultActor`（默认 `yang`）。

实际用了哪一级会记在每条记录的 `actor_source` 上（`param` / `im_source_name` / `im_source_id` / `default`）。`ledger_doctor` 会按这个分组报数——如果全是 `default`，说明 dsh-im 的"上下文增强"还没打开。

## 数据在哪，怎么保证不丢

- 全部记录：`<dataDir>/entries.ndjson`，一行一条、只追加；改错 = 追加新版本，历史不删。
- 坏行不会丢：解析不了的会被复制到 `<dataDir>/quarantine/`。
- `<dataDir>` 是独立 git 仓库，默认 60 秒无新写入后自动提交一条（只本地，不远程）。
- 导出的 markdown/CSV 在 `<dataDir>/exports/`，删了能重建。

## 冒烟测试（重启后照做一遍）

1. `午饭32` → 回执"已记 · 今天 支出 ¥32.00 [家里]"，再说 `这个月花了多少`。
2. `昨天打车18` → 记到昨天。
3. `老陈拿了两双，先欠着480`（先记住店里：`以后店里的事都记店里` 或直接说 `店里：老陈…`）→ 应收 +480。
4. `老陈还了300` → 还欠 180。
5. `改了，最后那笔是500不是480` → 回执显示 480 → 500。
6. `外面还欠多少` → 按人列表 + 账龄。
7. 让父母用微信各发一句，跑 `ledger_doctor`：`actor_sources` 里应出现 `im_source_name`（有昵称）或 `im_source_id`（没昵称），而不是清一色 `default`。

## 已知限制

- 长辈手机上的一次回执最多 4 行、不含英文和编号；金额写"¥32.00"而不是"32元"。
- "几十块""大概三百" 这类模糊金额会先问一句，不会瞎记。
- 未来的日期（"明天"）拒绝记录；跨天凌晨 4 点前算前一天。
- 散客赊账不按人记账龄，只记总数。
